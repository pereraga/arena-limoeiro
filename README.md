# Arena Limoeiro - Complexo Poliesportivo e Lazer

Sistema completo de agendamento de quadras esportivas, mensalistas e produtos para a Arena Limoeiro.

## Deploy na Vercel e Supabase
1. Execute o script supabase/schema.sql no SQL Editor do Supabase.
2. No painel da Vercel, conecte este repositorio e adicione as variaveis de ambiente VITE_SUPABASE_URL e VITE_SUPABASE_ANON_KEY.
3. Deploy automatico com HTTPS.
